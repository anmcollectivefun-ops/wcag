# ANM Access — plan oceny dostępności

**Cel projektowy:** WCAG 2.2 AA. **Status:** audyt ekspercki nieprzeprowadzony. Ten dokument nie jest certyfikatem zgodności.

| Obszar | Test manualny | Status |
|---|---|---|
| Klawiatura | Przejdź przez wszystkie elementy Tab / Shift+Tab; sprawdź skip link, fokus, formularz, zmianę statusu i eksport. | Do wykonania |
| Fokus | Sprawdź widoczną ramkę fokusu, kolejność nawigacji, fokus po błędzie i zmianie widoku. | Do wykonania |
| Czytnik ekranu | Sprawdź NVDA + Firefox i VoiceOver + Safari: nagłówki, etykiety, opisy pól, komunikaty błędów, wyniki filtrowania. | Do wykonania |
| Zoom i reflow | Sprawdź 200% i 400% powiększenia oraz szerokość 320 CSS px bez utraty informacji. | Do wykonania |
| Kontrast | Zmierz rzeczywisty kontrast tekstu, ikon, kontrolek, statusów, focusu i trybu wysokiego kontrastu. | Do wykonania |
| Formularz | Spróbuj wysłać formularz pusty, z krótkim opisem i po poprawie błędów. | Do wykonania |
| Skalowanie tekstu | Sprawdź czy 200% wielkości tekstu nie powoduje ucięcia treści. | Do wykonania |
| Ruch i czas | Sprawdź `prefers-reduced-motion`, komunikaty na żywo i brak ograniczeń czasu. | Do wykonania |
| Mobile / dotyk | Sprawdź rozmiary celów dotykowych, orientację ekranu i brak poziomego przewijania. | Do wykonania |

Po testach: zapisz wersję kodu, datę, przeglądarkę, środowisko, kryterium sukcesu WCAG, wynik, zrzut/odtworzenie błędu, poprawkę i wynik retestu. Następnie zleć niezależną ocenę przed publikowaniem stwierdzeń o pełnej zgodności.

Źródła odniesienia: https://www.w3.org/TR/WCAG22/ i https://www.w3.org/WAI/test-evaluate/.
